# FixRecoveredMedia

This Python script fixes your recovered media files (currently just JPEG and MP4) by reading their metadata and renaming them to their original, structured file names, which you can define yourself (e.g. IMG_DATE_TIME.jpg). This means that all of your data can be organized as if it had never gone through recovery.
